## XLSX 适配候选审计

`trkbt10/ooxml` 只能作为待验证候选，不视为已选依赖。Milestone 4 前必须验证公式原文、工作表名称、错误处理、真实样例成功率和维护风险；未通过时使用 JSON v1 与 CSV 值导入作为 Plan B。

## MoonSheet 的差异化

MoonSheet 不以“能显示网格”或“能读取 XLSX”为核心差异，而是把以下能力组成完整产品：

- MoonBit 原生公式解析与计算。
- 基于依赖图的增量重算。
- 循环引用路径与错误传播根因。
- 面向普通用户的公式解释与浏览器调试体验。
- 同一核心跨 CLI、MoonBit 库和浏览器运行。

## 重复风险判定

若发现 MoonBit 项目同时覆盖公式计算、依赖图、增量重算和错误解释中的三项，并具备持续维护与成熟用户体验，则暂停开发并重新评审。仅有 OOXML、DataFrame、Parser 或网格 UI 不构成直接同类。

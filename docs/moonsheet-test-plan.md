# MoonSheet 测试与验证计划

| 项目 | 内容 |
|---|---|
| 状态 | Approved for repository bootstrap |
| 最后更新 | 2026-06-09 |

## 需求追踪

| 规格 | 主要验证 |
|---|---|
| 公式语义 | 表驱动单元测试、参考差异测试 |
| JSON v1 | Schema 正反例、稳定导出快照 |
| 增量重算 | 与全量重算逐单元格差异测试 |
| 诊断 | 错误码、排序、路径和中英文快照 |
| CLI | 命令、stdout/stderr、JSON 信封和退出码 |
| 浏览器 | 核心旅程、状态、键盘和隐私测试 |

## 发布阻断不变量

- 相同输入和语义版本产生相同值、诊断和稳定排序。
- 增量重算与全量重算逐单元格完全一致。
- 未受影响的单元格不进入本次重算集合。
- 上游被重算但值和诊断未变时，传播停止。
- AST、值和诊断等价必须遵循技术设计，不使用显示字符串代替。
- 不支持的公式返回 `UNSUPPORTED_FEATURE`。
- CLI、浏览器与库使用同一核心语义。

## 公式与地址测试

- 列边界：`Z`、`AA`、`ZZ`、`AAA`、`XFD`；拒绝 `XFE`。
- 行边界：`1`、`1048576`；拒绝 `0` 和超界。
- 跨表、引号表名、绝对和混合引用。
- 反向范围规范化与先行后列展开。
- 空白在标量、比较、范围聚合中的不同语义。
- 链式比较拒绝、函数参数数量、数值溢出和非有限结果。
- `IF` 短路：未选择分支中的运行时错误不传播。
- `IF` 未选择分支中的结构错误仍然报告。
- 易变函数和未知函数明确拒绝。

## 增量计算测试矩阵

| 编辑 | 期望 |
|---|---|
| source 完全相同 | 0 个重算 |
| `1` 改为 `1.0` | 规范化值相同，不修改工作簿、不重算 |
| 公式空格变化且 AST 相同 | 只提升 content_version，不重算 |
| 诊断仅切换显示语言 | 不继续传播 |
| 公式引用从 A1 改为 B1 | 更新依赖边，重算旧/新影响并集 |
| 上游值变化但下游结果不变 | 下游计算后停止继续传播 |
| 上游诊断变化 | 下游诊断重新计算 |

随机生成有向无环工作簿，对每次编辑同时运行增量和全量计算，结果、诊断必须完全一致。

## 多错误与循环测试

- 同一单元格拥有两个不同根错误。
- 两个相同类型根错误距离不同。
- 距离和类型相同但地址不同。
- 自循环、多个独立循环、相连循环。
- 循环路径和主错误在重复运行中完全一致。
- 存在循环时，无关区域仍得到正确结果。

## JSON 与 CLI 测试

- JSON v1 最小文件、完整文件、未知字段、重复表名、非法地址、显式 null、字段冲突和超限。
- 稳定导出重复执行字节一致。
- 每个 CLI 命令验证成功、诊断、参数错误、文件错误和内部错误退出码。
- `--json` stdout 使用快照；不得混入日志。

## 浏览器测试

- 首次进入、空白、加载、计算、解析错误、文件错误、超限和内部错误状态。
- 网格与公式栏编辑、取消、应用、依赖跳转。
- 键盘完成主演示核心旅程。
- 网络监控断言工作簿内容不上传。
- 桌面 Chrome 为发布阻断浏览器；Firefox 为兼容性检查。

## 性能基准

固定环境：发布构建、桌面 Chrome 最新稳定版、8 核 CPU、16 GB 内存；CI 记录趋势，本地标准机执行发布门槛。

| 数据集 | 门槛 |
|---|---:|
| 50,000 非空单元格、100,000 依赖边首次计算 | p95 ≤ 2 s |
| 200,000 非空单元格加载并计算 | ≤ 10 s，峰值内存 ≤ 1 GB |
| 影响范围 ≤ 500 的单点编辑 | p95 ≤ 100 ms |
| 影响范围 ≤ 5,000 的单点编辑 | p95 ≤ 500 ms |
| 网格滚动与选择 | 主线程长任务不得连续超过 100 ms |

每项至少预热 3 次、测量 20 次并报告 p50/p95。

## 产品验证

5 名目标用户在无口头指导下完成：定位错误结果、查看根因、修复并确认恢复。记录完成率、耗时、误操作和原话。中位完成时间超过 3 分钟或成功少于 4 人，阻断申报版冻结。

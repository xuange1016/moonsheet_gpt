## 当前事实

当前目录已作为正式 `moonsheet` 仓库初始化，没有 MoonSheet 源代码或可编译包。后续开发直接在此仓库进行，不创建嵌套仓库，不纳入无关构建产物或旧 Git 历史。

## Gate 0：文档冻结

通过条件：

- 公式、地址、范围、错误、JSON、CLI、浏览器和性能规格不存在阻断性歧义。
- 所有 Must 要求可追踪到测试或产品验证。
- 新仓库命名和结构已锁定。

## Milestone 0：技术探针，目标 1 天

探针必须写在新仓库的 `spikes/` 或首批核心包中，并产生可执行测试。

| 探针 | 固定输入 | 通过条件 |
|---|---|---|
| 公式解析 | `=IF(A1>0,SUM(B1:B3),C1/0)` | AST、引用和源码范围符合语义规格 |
| 图与增量重算 | 1,000 单元格菱形依赖图 | 修改叶子后重算集合准确；与全量结果一致 |
| 循环与多错误 | 自引用、三节点循环、两个根错误 | 循环路径和主错误排序稳定 |
| 浏览器调用 | 预算表最小页面 | 浏览器调用 MoonBit JS 核心并显示结果与诊断 |
| Wasm 比较 | 同一预算表 | 记录正确性、性能和开发复杂度，不强制采用 |

**Gate 1：** 前四项全部通过才进入 MVP；Wasm 仅按技术设计门槛决定是否采用。

## Milestone 1：计算核心，目标 2026-06-17

用户结果：CLI 可以验证并计算 JSON v1 工作簿。

- 建立新仓库、包结构、CI 和测试框架。
- 实现地址、值、工作簿和 JSON v1。
- 实现 Lexer、Parser、AST 和源码范围。
- 实现依赖图、循环检测、全量计算。
- 实现 MVP 运算符与函数。
- 实现 `validate`、`calculate` 命令。

退出条件：CLI 契约测试通过；公式参考用例通过；无浏览器 UI 依赖。

## Milestone 2：增量计算与诊断，目标 2026-06-25

用户结果：修改输入后局部重算，并解释根因与影响范围。

- 实现编辑变化判定和图更新。
- 实现值/诊断变化驱动的传播停止。
- 实现多根因排序、循环路径和解释模板。
- 实现 `explain` 命令与结构化 ViewModel。
- 建立 50,000 / 200,000 单元格基准。

退出条件：增量与全量差异测试 100% 一致；量化性能门槛通过。

## Milestone 3：浏览器 MVP，目标 2026-07-05

用户结果：在浏览器完成完整核心旅程。

- 实现页面骨架、虚拟化网格、公式栏和检查器。
- 接入 MoonBit Core，不在 UI 重复计算逻辑。
- 实现所有页面状态、键盘路径和错误交互。
- 完成预算表、循环、多根因示例。
- 完成 5 人可用性测试并修复主要障碍。

退出条件：核心旅程、性能、隐私和可访问性验收通过。

## Milestone 4：申报与比赛增强，目标 2026-07-10 起

- 发布 Mooncakes 包和在线演示。
- 按门槛决定 XLSX 与 Wasm 增强。
- 增加真实样例、基准报告和架构说明。
- 完成申报 PDF、视频和现场演示预案。

## 工作顺序约束

- 每个功能先引用对应规格，再实现，再加入测试。
- 核心正确性未通过前，不扩大函数数量。
- 浏览器核心旅程未通过前，不做视觉装饰性功能。
- XLSX、Wasm 和高级函数不得挤占 MVP 截止时间。
- 文档状态只能在验收证据存在后改为 Implemented。

## 新仓库启动清单

1. 在当前 `moonsheet` 文件夹初始化 Git，并关联公开 GitHub 仓库 `xuange1016/moonsheet_gpt`。
2. 初始化 `moonsheet/moonsheet` MoonBit 模块与最小可编译包。
3. 保留本目录 `docs/`、README 和 LICENSE 作为正式仓库基线。
4. 配置 CI：check、test、文档链接、格式检查。
5. 执行 Milestone 0，不迁移 `_build` 或无关 Git 历史。

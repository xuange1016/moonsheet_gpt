# MoonSheet 决策记录

## D-001：选择 MoonSheet

| 字段 | 内容 |
|---|---|
| 日期 | 2026-06-09 |
| 状态 | Confirmed |
| 决策 | 将比赛主项目确定为 MoonSheet：MoonBit 可解释电子表格计算与公式调试引擎 |
| 原因 | 用户问题广泛且易理解；公式引擎、依赖图、增量计算和错误诊断具备技术深度；浏览器主演示直观；核心能力适合由 MoonBit 跨 native 与浏览器实现 |
| 重审条件 | 技术探针无法打通公式计算、增量更新或浏览器调用；发现成熟 MoonBit 同类覆盖核心差异化能力 |

## D-002：坚持单一主旅程

| 字段 | 内容 |
|---|---|
| 日期 | 2026-06-09 |
| 状态 | Confirmed |
| 决策 | MVP 只保证“打开工作簿 → 计算 → 修改 → 局部重算 → 定位错误 → 修复”完整旅程 |
| 原因 | 完整 Excel 范围不可控；一等奖竞争力来自完整体验与核心引擎，而不是功能数量 |
| 后果 | 协作、宏、透视表、打印、云存储和完整 XLSX 兼容均不进入首版承诺 |

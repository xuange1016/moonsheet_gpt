# MoonSheet MVP 产品需求

| 项目 | 内容 |
|---|---|
| 状态 | Approved for Milestone 0 |
| 规格版本 | MVP v1 |
| 最后更新 | 2026-06-09 |

## 产品承诺

MoonSheet 帮助用户计算并调试电子表格公式。MVP 必须完整支持以下旅程：

```text
打开示例或 JSON 工作簿
→ 查看计算结果
→ 修改单元格
→ 查看局部重算范围
→ 定位公式错误、循环引用或上游错误
→ 修复后确认结果恢复
```

## 目标用户与主演示

- 第一用户：需要排查复杂表格公式的数据分析人员、开发者和重度表格用户。
- 主演示：预算表中一个错误输入污染多个结果；用户从错误结果反查根因并修复。
- 演示理解门槛：不要求用户理解编译器、图算法或 MoonBit。

## MVP 功能要求

| ID | 能力 | 验收行为 |
|---|---|---|
| R1 | 工作簿 | 打开、编辑并保存 MoonSheet JSON v1 工作簿 |
| R2 | 地址与公式 | 支持已锁定的 A1 地址和 MVP 公式语法 |
| R3 | 计算 | 按明确语义计算值、运算符、引用、范围和函数 |
| R4 | 依赖 | 选中单元格时查看直接上游、直接下游和完整影响范围 |
| R5 | 增量重算 | 编辑后只重算语义上可能受影响的单元格 |
| R6 | 循环诊断 | 展示稳定、可复现的循环路径 |
| R7 | 错误传播 | 区分根错误和下游依赖错误，并展示确定性路径 |
| R8 | 公式解释 | 展示公式、代入值、计算步骤和结果 |
| R9 | 浏览器工作台 | 完成核心旅程，包含加载、空白、错误和超限状态 |
| R10 | CLI | 使用稳定命令、JSON 输出和退出码验证核心引擎 |
| R11 | 示例 | 提供预算表、循环引用、多上游错误三个案例 |

## 已锁定的 MVP 公式范围

- 值：数字、文本、布尔值、空白、错误值。
- 运算符：`+ - * /`、`= <> < <= > >=`、括号、一元 `-`。
- 地址：A1 风格；支持同表引用、跨表引用、绝对和混合引用。
- 范围：矩形范围，例如 `A1:B3`、`Sheet2!$A$1:B3`。
- 聚合函数：`SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`。
- 控制函数：`IF`，采用短路求值，不作为普通纯函数处理。
- 不支持易变函数：MVP 不实现 `RAND`、`NOW`、`TODAY` 等函数。

完整语义以 [formula-semantics.md](formula-semantics.md) 为唯一事实源。

## MVP 明确不做

- 不承诺完整 Excel 兼容。
- 不支持宏、VBA、外部链接、数组公式或动态数组。
- 不支持多人协作、账号、云存储、图表、透视表和打印。
- 不自动修改工作簿，不使用大模型生成计算结论。
- XLSX 不属于 MVP 发布阻断项；是否进入比赛增强版按明确门禁决定。

## 浏览器验收

- 首次打开直接加载预算表示例，并提供 3 步引导。
- 用户可以通过网格或公式栏修改单元格。
- 修改后高亮本次重算单元格，解释面板同步更新。
- 错误单元格展示错误码；点击后显示根错误、路径和修复建议。
- 工作簿数据默认只保存在浏览器内存；导出需用户主动操作。
- 所有异步操作均展示加载、成功或失败反馈。

详细交互规格见 [browser-workbench-spec.md](browser-workbench-spec.md)。

## 成功指标

| 指标 | MVP 门槛 |
|---|---:|
| 核心任务完成率 | 5 名试用者中至少 4 名完成 |
| 核心任务完成时间 | 中位数不超过 3 分钟 |
| 增量与全量计算一致性 | 自动化用例 100% 一致 |
| 支持语义正确率 | 参考用例 100% 通过 |
| 50,000 单元格首次计算 | 桌面 Chrome p95 不超过 2 秒 |
| 单输入局部更新 | 受影响单元格不超过 500 时 p95 不超过 100 ms |
| 浏览器编辑反馈 | p95 不超过 100 ms |

性能测试环境与数据集在测试计划中锁定。

## 发布阻断条件

- JSON v1、公式语义、CLI 或浏览器行为与规格不一致。
- 增量重算与全量重算结果不同。
- 未支持能力被静默接受。
- 错误传播结果不稳定。
- 浏览器核心旅程无法离线完成。

# MoonSheet 项目申报书草稿

## 项目名称

MoonSheet：基于 MoonBit 的可解释电子表格计算与公式调试引擎

## 项目简介

电子表格广泛用于预算、财务、运营和数据分析，但复杂公式一旦出现错误，用户通常只能看到最终错误值，很难判断结果如何得出、错误来自哪里、修改会影响哪些单元格。MoonSheet 使用 MoonBit 实现公式解析、依赖图、增量重算和结构化诊断，并提供浏览器工作台，让用户像调试程序一样理解和修复电子表格公式。

## 核心创新与价值

- 使用 MoonBit 构建可复用的跨平台电子表格计算核心。
- 修改输入后只重新计算受影响单元格，展示 MoonBit 的工程与性能能力。
- 不只报告错误，还展示循环引用路径、根错误和下游传播范围。
- 通过“通俗解释 + 专业信息”降低复杂公式排查门槛。
- 浏览器默认本地运行，不上传用户工作簿。

## MVP 演示

用户打开预算表示例，修改销售额后相关结果立即更新；随后故意制造引用错误，MoonSheet 展示错误源、依赖链和受影响结果。用户修复根因后，工作簿恢复正常。核心计算同时可通过 CLI 与 MoonBit 库调用。

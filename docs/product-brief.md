## 一句话说明

MoonSheet 是使用 MoonBit 开发的电子表格计算与公式调试引擎：它不仅计算公式，还能告诉用户某个结果为什么错误、错误从哪里传播而来，以及修改一个单元格后哪些结果需要重新计算。

## 用户问题

复杂电子表格经常承担预算、财务、运营和实验数据计算，但公式散落在大量单元格中。用户通常只能看到最终的 `#VALUE!`、`#REF!` 或错误数字，很难回答：

- 这个结果依赖哪些输入？
- 错误最早从哪个单元格出现？
- 修改一个输入后，哪些单元格会受影响？
- 工作簿里是否存在循环引用或高风险公式？

## 第一目标用户

第一目标用户是需要检查复杂表格公式的开发者、数据分析人员和重度表格用户。比赛演示以“预算表错误定位”为核心场景，不要求评委理解编译器原理。

## 产品价值

```text
导入或创建工作簿
  → MoonSheet 计算公式
  → 用户修改输入
  → 仅重新计算受影响单元格
  → 出错时展示依赖链、传播路径和通俗解释
  → 用户修复并验证结果
```

## 为什么适合 MoonBit

- 公式解析、类型化值模型、依赖图、增量计算和诊断均由 MoonBit 实现。
- 同一核心引擎可面向 native CLI 与浏览器 Wasm/JS 后端。
- 可通过大量公式、深依赖链和局部更新展示性能与工程质量。
- 最终产物既是可复用 MoonBit 库，也是普通用户可直接体验的浏览器产品。

## 成功标准

- 新用户在 3 分钟内完成“打开示例、定位错误源、修复并重新计算”。
- 支持 MVP 承诺的公式与函数，并对不支持的语法给出明确诊断。
- 修改单元格后，只重新计算语义上受影响的依赖子图。
- 循环引用和错误传播链可以稳定、清晰地展示。
- 核心计算结果通过参考实现与人工样例交叉验证。
- 浏览器主演示全程本地运行，不上传工作簿。

## 关键风险假设

| 假设 | 当前证据 | 验证方式 |
|---|---|---|
| MoonBit 适合实现公式解析与依赖图 | 尚未验证 | Milestone 0 技术探针 |
| MoonBit JS 核心可稳定接入浏览器 UI | 尚未验证 | 浏览器最小调用探针 |
| 用户重视“错误解释”而非又一个表格 UI | 合理但未验证 | 5 名目标用户任务测试 |
| MoonBit 生态没有成熟同类 | 初步检索未发现 | 申报前重复查重 |

## 明确边界

MoonSheet 不是完整 Excel 替代品，不承诺完整兼容 Excel，不提供多人协作、宏、透视表、打印排版或云端存储。MVP 聚焦“正确计算、增量更新、解释错误”这一条完整用户旅程。
